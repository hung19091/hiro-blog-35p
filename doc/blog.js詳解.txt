==================================================
檔案用途
==================================================

此檔案是一個前端部落格首頁（Article List Page）控制器。

主要負責：

1. 從 Firebase Firestore 讀取文章
2. 篩選 published = true 的文章
3. 依照建立時間排序
4. 動態產生標籤(Tag)篩選器
5. 支援文章分類過濾
6. 支援分頁顯示
7. 動態產生文章清單
8. 設定 SEO Meta Tag
9. 產生文章連結 URL

屬於典型：

Firestore
↓
文章資料
↓
前端處理
↓
DOM Render
↓
使用者瀏覽

模式。

==================================================
扣分原因總結
==================================================

1. Tag可能產生Stored XSS
2. 使用innerHTML輸出大量內容
3. 使用window全域函式
4. onclick內嵌事件不利維護
5. 一次載入全部文章無法水平擴充
6. Firestore Rules未確認
7. 缺少Loading與Retry機制
8. 缺少Slug唯一性檢查

以企業級、5年以上維護的專案標準來看，這份程式碼屬於：

中大型網站可用
↓
具備基本架構
↓
但尚未達到高流量商業系統等級

若文章量超過 5,000 ~ 10,000 篇，建議改為：

Firestore Cursor Pagination
+
Server Side Rendering (SSR)
+
前端框架(Vue/React)
+
集中式 State Management

才能支撐長期維護與擴充。

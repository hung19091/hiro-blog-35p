==================================================
index.html 程式碼詳解
==================================================

來源檔案：

index.html

==================================================
檔案用途
==================================================

這是一個技術部落格首頁。

主要功能：

1. SEO 優化
2. Open Graph 社群分享
3. Twitter Card
4. JSON-LD 結構化資料
5. Tailwind CSS 樣式
6. Firebase 整合
7. 文章列表顯示
8. Tag 分類篩選
9. 分頁功能
10. 自訂訊息視窗

==================================================
第1行
==================================================

原始碼：

<!DOCTYPE html>

作用：

宣告此頁面使用 HTML5 標準。

為什麼需要：

瀏覽器看到此行後會使用標準模式解析頁面。

如果沒有：

可能進入相容模式。

常見問題：

1. 部分 CSS 失效
2. 排版錯亂
3. 不同瀏覽器結果不一致

==================================================
第2行
==================================================

原始碼：

<html lang="zh-Hant" class="dark">

作用：

設定整個網站的語言與主題模式。

說明：

lang="zh-Hant"

代表：

繁體中文

用途：

1. SEO
2. 搜尋引擎辨識語言
3. 螢幕閱讀器朗讀

--------------------------------------------------

class="dark"

代表：

網站預設套用 Dark Mode。

Tailwind 看到 dark 類別後：

會啟用所有 dark: 開頭的樣式。

==================================================
第5行
==================================================

原始碼：

<meta charset="UTF-8">

作用：

設定網頁字元編碼。

UTF-8 優點：

1. 支援中文
2. 支援日文
3. 支援韓文
4. 支援 Emoji

如果省略：

可能出現亂碼。

==================================================
第6行
==================================================

原始碼：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

作用：

支援手機版顯示。

意思：

width=device-width

代表：

畫面寬度等於裝置寬度。

--------------------------------------------------

initial-scale=1.0

代表：

預設縮放比例 100%。

沒有此設定時：

手機可能把整個網站縮成很小。

DevLog | 現代化技術部落格

用途：

1. SEO
2. 書籤名稱
3. 瀏覽器標籤名稱

==================================================
第10行

<meta name="description" ...>

SEO 好處：

提高點擊率。

==================================================
第11行
==================================================

原始碼：

<meta name="robots" content="index,follow,max-image-preview:large,max-snippet:-1,max-video-preview:-1">

作用：

告知搜尋引擎應如何索引。

index

允許收錄。

--------------------------------------------------

follow

允許追蹤連結。

--------------------------------------------------

max-image-preview:large

允許大型圖片預覽。

--------------------------------------------------

max-snippet:-1

允許完整摘要。

==================================================
第12行
==================================================

原始碼：

<link rel="canonical" id="canonical-link" href="">

作用：

Canonical URL。

用途：

避免重複內容問題。

例如：

/index.html

/

/?page=1

搜尋引擎可能認為是不同頁面。

Canonical 用來指定：

哪個才是正式網址。

--------------------------------------------------

pathname

--------------------------------------------------

replace()

結果：

/

--------------------------------------------------

最後得到：

https://abc.com/

3. twitter:url

==================================================
程式設計角度改善建議
==================================================

改善項目 1

目前：

使用字串組合計算網址。

建議：

使用 URL 物件。

優點：

1. 可讀性更高
2. 不容易出錯
3. 支援更多情境

--------------------------------------------------

改善項目 2

目前：

直接使用 Tailwind CDN。

適合：

開發環境。

正式環境建議：

預編譯 CSS。

優點：

1. 更快
2. 更小
3. SEO 更好

--------------------------------------------------

改善項目 3

目前：

onclick="closeModal()"

建議：

使用 addEventListener()

優點：

1. 維護性高
2. 易於測試
3. JavaScript 與 HTML 分離
